# Les cas d'usage

*Cette partie est en attente. Elle s'écrit au chapitre 13 du rang 10,
qui y absorbe `usecases/` (D1518, D1520). Le [plan](../README.md) en
tient l'avancement.*

Les cas d'usage sont cinq applications complètes. Chacun présente le
besoin qui l'a produit, sa configuration et les documents qui en
sortent :

- le tiny, une entité et quatre champs ;
- l'enquête ;
- le véhicule ;
- la banque ;
- l'entrepôt.

En attendant, chaque cas se lit dans [`usecases/`](../../usecases/), et
sa configuration dans [`examples/`](../../examples/).
