Cuándo: cada mes, y antes de cualquier decisión de gasto.

1. Abrir [la evolución de los gastos por presupuesto](chart[ecriture.evolution_budget]); elegir el
   presupuesto y el período.
2. Leer el acumulado de cada mes: la curva dice si el presupuesto se desvía.
3. Volver a [los apuntes del presupuesto](banque.ecriture[par_operation]) en el período, para ver
   qué ha pesado.
4. Si un apunte está mal clasificado, reabrirlo y corregir su presupuesto — el referencial de
   presupuestos acepta la creación directa desde el campo.

> **No hacer**: crear un presupuesto por proveedor — el presupuesto dice para qué sirve el gasto,
> no a quién va; el lugar y el concepto llevan el resto.
