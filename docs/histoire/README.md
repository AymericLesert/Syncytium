# L'histoire

*Cette partie est en attente. Elle s'écrit en dernier au rang 10, quand
le registre se convertit (D1520). Le [plan](../README.md) en tient
l'avancement.*

L'histoire dit ce qui a été : le cheminement de la conception, les
décisions une à une, les questions ouvertes et closes, et le journal
des échanges. Les chapitres de Syncytium, eux, disent ce qui est.

En attendant, tout se lit dans le registre :
[`conception.md`](../conception.md).
