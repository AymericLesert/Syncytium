When: every month, and before any spending decision.

1. Open [spending over time by budget](chart[ecriture.evolution_budget]); choose the budget and
   the period.
2. Read each month's total: the curve shows whether the budget is drifting.
3. Go back to [the budget's entries](banque.ecriture[par_operation]) over the period, to see what
   weighed.
4. If an entry is misfiled, reopen it and correct its budget — the budget reference list accepts
   direct creation from the field.

> **Do not**: create one budget per supplier — the budget says what the spending is for, not who
> it goes to; the place and the description carry the rest.
