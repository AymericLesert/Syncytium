## Le contexte (D1023)

**« Pour le cas 5 [le cas 7 depuis D1027], le projet s'appelle PDCA — je te demanderai
d'analyser et de transcrire un vieux projet dans le nouveau cadre et
de moderniser l'affichage et les rapports. Il n'y a pas de hook mais
l'idée est d'utiliser l'IA pour générer la configuration d'un projet
en vue d'un refactoring. Cela va inclure la documentation
auto-générée. »** (l'auteur, le 21/09/2026 ; « une gestion de projets »
— D756)

*(le projet source viendra de l'auteur à l'ouverture)*

## Ce que le cas éprouve

- **la transcription d'un existant par l'IA** — l'analyse du vieux
  projet, la configuration Syncytium générée en vue du refactoring ;
- **l'affichage et les rapports modernisés** — les surfaces du
  catalogue sur un modèle repris ;
- **la documentation auto-générée** (D258/D840) — ce que la
  configuration dit d'elle-même ;
- l'application métier collaborative : les groupes, les droits, les
  cycles de vie (D421–D427).
