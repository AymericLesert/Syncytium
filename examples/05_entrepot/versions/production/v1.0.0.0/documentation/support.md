# Le support

L'entrepôt est tenu par l'entreprise elle-même : aucun prestataire, aucun engagement de délai.

## Qui répond

- **Une anomalie** — l'administration de l'entrepôt : elle vérifie la reprise de la nuit, relance une migration,
  corrige la configuration.
- **Une question** — la logistique, qui connaît les dépôts, les emplacements et les mouvements ; elle fait suivre au
  bureau d'études, au commercial ou aux achats quand la question porte sur leur domaine.
- **Une évolution** — la direction, qui arbitre et planifie dans une version à venir.

## Comment joindre l'entreprise sans l'application

Par courriel à entrepot@entreprise.example, ou à l'accueil de l'entreprise aux heures d'ouverture.
