Cuándo: al establecer una suscripción, un alquiler, cualquier apunte que se repite.

1. Abrir [los apuntes por fecha de operación](banque.ecriture[par_operation]) y seleccionar el
   apunte modelo — el primero de la serie, ya registrado.
2. Pulsar [Duplicar](banque.ecriture.dupliquer): el formulario pide el paso — el día, la semana, el
   mes, el trimestre — y las dos fechas, del primer ejemplar al último.
3. Revisar: el número de apuntes que se crearán; luego validar.
4. Comprobar la serie en la lista: un apunte por paso, con el concepto y el importe del modelo, sin
   fecha contable — cada uno se punteará con su extracto.

> **No hacer**: duplicar un apunte ya punteado esperando conservar su fecha contable — las copias
> nacen sin fecha contable, es el extracto el que la pone.
