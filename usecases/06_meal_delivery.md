**« Un ERP dédié à la livraison de repas à domicile. »** (D756) —
le plus riche de l'échelle.

**« Pour le cas 6, c'est le plus ambitieux. Ce projet est
actuellement utilisé en production depuis une dizaine d'années. Je
souhaite que Syncytium soit le socle de sa refonte. Je te transmettrai
documentation et code. Ce sera l'occasion d'avoir un vrai projet de
validation. Ici, cette phase va permettre de valider toutes les
composantes que nous avons abordées jusqu'ici. Par contre, la mise à
disposition complète fera l'objet d'un vrai projet dont les détails
seront portés dans un autre projet GitHub. En plus de l'existant, tu
intégreras aussi le module de chat IA. »** (l'auteur, le 21/09/2026 —
D1024)

## Ce que le cas éprouve

- **tout** — la validation de toutes les composantes abordées, sur un
  existant réel : le multi-modules et les acteurs multiples (les
  clients, les cuisines, les livreurs, l'administratif), la
  géolocalisation (D294/D637–D638) et les tournées, les connecteurs
  en nombre (le smtp, le webhook, le storage…) ;
- **le module de chat IA** (D957–D960) — en plus de l'existant ;
- **la frontière** : le cas et l'exemple vivent ici, la mise à
  disposition complète dans un autre projet GitHub.
