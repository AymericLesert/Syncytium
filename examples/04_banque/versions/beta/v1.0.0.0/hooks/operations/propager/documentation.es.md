# propager — la modificación de los similares

Modifica el concepto y el importe de todos los apuntes «similares»: el
mismo concepto Y el mismo importe que antes de la modificación, con
fecha de operación ≥ la del apunte modificado. El recorrido: la lista
de similares → la selección → la modificación en masa, validada antes
del sellado.
