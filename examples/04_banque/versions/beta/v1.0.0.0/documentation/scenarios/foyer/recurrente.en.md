When: when setting up a subscription, a rent, any entry that repeats.

1. Open [the entries by transaction date](banque.ecriture[par_operation]) and select the model
   entry — the first of the series, already entered.
2. Press [Duplicate](banque.ecriture.dupliquer): the form asks for the step — day, week, month,
   quarter — and the two dates, from the first copy to the last.
3. Review: the number of entries that will be created; then confirm.
4. Check the series in the list: one entry per step, with the model's description and amount, with
   no posting date — each one will be reconciled with its own statement.

> **Do not**: duplicate an already reconciled entry hoping to keep its posting date — the copies
> are created without a posting date, the statement sets it.
