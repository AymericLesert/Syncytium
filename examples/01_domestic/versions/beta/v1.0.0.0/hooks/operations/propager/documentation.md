# propager — la modification des similaires (D774)

Modifie le libellé et le montant de toutes les écritures
« similaires » : le même libellé ET le même montant qu'avant la
modification, à la date d'opération ≥ celle de l'écriture modifiée.
Le déroulé : la liste des similaires → la sélection → la
modification en masse, validée avant le scellé (D446/D594).
