# La présentation

*Cette partie est en attente. Elle s'écrit à la partie 0 du rang 10,
après les chapitres de Syncytium et les cas d'usage (D1519, D1520). Le
[plan](../README.md) en tient l'avancement.*

La présentation est la porte d'entrée de la documentation. Elle part de
la configuration du tiny, une entité et quatre champs, et la déplie clé
par clé jusqu'à l'application complète. Elle ouvre ensuite le menu de la
documentation.

En attendant, le tiny se lit dans son cas d'usage :
[`usecases/01_tiny.md`](../../usecases/01_tiny.md).
